# Step 02 — 工具系统

## 只解决一件事

给 Step 01 的循环接上**真实工具**：

| 工具 | 作用 |
|------|------|
| `read_file` | 读文件（带行号） |
| `write_file` | 写/覆盖文件 |
| `edit_file` | 精确字符串替换（必须唯一匹配） |
| `run_shell` | 执行 shell 命令 |

## 关键不变量

1. **工具 schema** 发给模型（让它知道能调什么）。
2. **工具执行** 在本地 Python 里完成，结果变成字符串。
3. **结果必须回到 messages**，否则模型不知道工具跑完了。

## 本步仍不做

权限确认、mtime 防呆、路径沙箱、并行执行……

## 怎么跑

```bash
python steps/02_tools/run.py "读取 README.md 的前 20 行并总结"
```
